# Projects

What students and researchers have built on Sage blades. These projects came out of the [2026 Sage Summer Camp](/docs/events/2026-Sage-Summer-Hackathon), held at UIC's EVL in July 2026.

| Project | What it does | Topic |
| --- | --- | --- |
| [Sage-NDP-SciDx MCP](/science/2026/ndp-scidx-mcp) | Adds tools to the Sage MCP server for publishing Sage data to the National Data Platform and streaming it live | Data, AI assistants |
| [Acoustic Bat Detection](/science/2026/bat) | Records ultrasound and detects and classifies bat calls at the edge | Bioacoustics |
| [Air Quality Intelligence](/science/2026/air-intelligence) | Asks whether camera images can tell healthy air from unhealthy air | Air quality, vision |
| [Manoomin Vision](/science/2026/manoomin-vision) | Tracks wild rice growth stages from a Sage node camera | Ecology, vision |
| [Dangerous Animal Detection](/science/2026/dangerous-animal-detection) | Detects animals, rates how dangerous they are, and sends alerts | Wildlife, vision |
| [Drought Early Warning](/science/2026/drought-early-warning) | Combines weather, soil, and camera data for early drought warnings | Water, multimodal AI |
| [Biotic Interaction](/science/2026/bisonn) | Explores edge computing for collecting data on how species interact | Ecology |
| [Mortimus Urgent Scheduling](/science/2026/mortimus-urgent-scheduling) | Decides which edge app should run next when results are time-critical | Scheduling |
| [Bat Activity Monitoring](/science/2026/bat-counter) | Counts bats in thermal video directly on Sage nodes | Ecology, vision |
| [Lightning-Ignition Watch](/science/2026/flashpoint) | Uses cameras, microphones, and weather data to locate lightning and watch for wildfires | Wildfire |
| [Long-Range Low-Power Networking](/science/2026/halow) | Sends images from a battery-powered camera over Wi-Fi HaLow | Networking |
| [Image Search at the Edge](/science/2026/image-search-at-the-edge) | Searches images by text or picture, entirely on one Jetson Thor | Multimodal AI |
| [Speech Redaction at the Edge](/science/2026/speech-redaction-at-the-edge) | Listens for birds without recording people's speech | Privacy, audio |
| [Weather Image Classification](/science/2026/weather-image-classification) | Picks out weather images using sensor data, for training image classifiers | Weather, vision |

Browse every project year on the [Sage Science page](/science).
