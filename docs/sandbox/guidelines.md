# Guidelines

How to share the Sandbox fairly with everyone else using it.

The Sandbox nodes are shared, and there is no booking system: anyone with access can log in to any node at any time. A little courtesy keeps it working for everyone.

:::tip[Do]

- **Spread out.** Pick a node that isn't busy, and have people in the same class or group start on different nodes.
- **Check first.** After logging in, run `who` and `top` to see who else is on the node and how busy it is.
- **Clean up.** Stop programs you're done with, and delete large files you no longer need.
- **Ask when unsure.** If you plan to run something big or long, mention it in Slack first (see [Get Help](./get-help)).

:::

:::danger[Don't]

- **Don't hog a node.** Avoid running heavy GPU jobs for hours when others may need the node.
- **Don't point cameras at people.** The cameras are aimed at objects on purpose. Don't move or re-aim them.
- **Don't change shared sensors.** Read from the weather station, but don't run its calibration or set-point commands.
- **Don't share your credentials.** Your SSH keys and the camera login are for you only.

:::

## Events and hackathons

During classes, workshops, or hackathons, organizers may set some nodes aside for the event. If you're planning an event that needs the Sandbox, contact the Sage team through [Get Help](./get-help).
